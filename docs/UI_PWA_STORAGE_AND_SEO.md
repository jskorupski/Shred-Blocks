## 4. Dual-Layer Persistence, 53-Bit Save Codec, Migration & Security (`STOR-01..02`, `ENDLESS-SAVE-01`, `SAVE-COMPAT-01`, `SAVE-SEC-01`)

- **Dual-Layer Storage ([`save-manager.ts`](../src/storage/save-manager.ts))**: Monotonic `writeSeq` writes synchronously to `localStorage` (`'shredblocks.save.v1'`) and mirrors asynchronously to `IndexedDB` (`'ShredBlocksDB'` / `'saves'`), reconciling on `init()`. Pre-import snapshots save to `PRE_IMPORT_BACKUP_KEY` (evicted automatically if `QuotaExceededError` occurs on massive Endless saves).
- **53-Bit Binary Save Codec ([`save-code.ts`](../src/storage/save-code.ts), [`qr-svg.ts`](../src/storage/qr-svg.ts))**: `0x02` columnar binary stream using 53-bit `writeVarint` / `readVarint` (never 32-bit shifts) + O(N) hash-chain LZ77 + base64url + CRC32 (`SB1-<base64url>-<crc32hex>`), plus legacy `0x7b` UTF-8 JSON stream decoding. `{ qrCompact: true }` caps QR exports at `1,500` records (prioritizing genuinely cleared stages ahead of `zenSkipped`-only entries via `selectEncodedRecordIds` without changing the `0x02` wire format) so QR codes always fit ISO 18004 Version 40 (`<= 2,953` bytes).
- **Live Save Backward-Compatibility & Migration Contract (`SAVE-COMPAT-01`)**:
  - Never rename `SAVE_STORAGE_KEY`, `IDB_DB_NAME`, `IDB_STORE_NAME`, or `appId` without reading and migrating the prior key/version first.
  - Keep `SKIN_IDS`, `TRAY_IDS`, `PARTICLE_IDS`, `QUALITY_TIERS`, and `sFlags` bit positions strictly **append-only** (reordering or removing entries breaks live `SB1-...` codes).
  - Add new `SavePayload` fields with safe defaults in `sanitizeSavePayload` (for older `localStorage`/`IndexedDB`/`.json` payloads missing those keys) and append-only tagged binary trailers after `0xa5` (such as `[0xa6, 0x4d]` in [`save-mode-ladders.ts`](../src/storage/save-mode-ladders.ts) and `[0xa8, 0x56]` for stepped `sfxVolume`/`musicVolume` `0..3`) in `packCompactSaveBytes` / `unpackCompactSaveBytes` — all outgoing saves and exports unconditionally write the latest `0xa5` + `[0xa6, 0x4d]` + `[0xa8, 0x56]` schema while decoders accept all legacy pre-`0xa5`/`0xa6`/`0xa8` formats and skip unknown future trailers cleanly.
  - Sequential forward migrations (`migrateSavePayload`: Economy v1 $\rightarrow$ v2, `modeLadderVersion: 0 -> 1`) run across all 4 load entry points (`constructor`, `init`, `importSaveCode`, `importSaveJson`), guarded by pinned canonical v1 fixtures in [`tests/unit/save-security.test.ts`](../tests/unit/save-security.test.ts).
- **Untrusted Save Security (`SAVE-SEC-01`)**: Treat `#import=`, pasted codes, JSON files, and storage as hostile. `validateSavePayloadV1` rebuilds a whitelisted payload; render save values strictly via `textContent` / `.value` (never `innerHTML`); preserve strict CSP (`script-src 'self'`, `object-src 'none'`, `base-uri 'none'`) + `frame-ancestors 'self'` + `X-Frame-Options: SAMEORIGIN` across `index.html`, `public/_headers`, `vite.config.ts`, and `vite.lan.config.ts`.
