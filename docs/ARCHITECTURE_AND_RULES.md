## Extension Checklists & Ergonomics (`ARCH-ERGONOMICS-01`)

1. **Adding a New Cosmetic Theme**:
   - Register the ID in `SkinId`, `TrayId`, or `ParticleStyleId` in [`src/core/types.ts`](../src/core/types.ts) and append it at the end of `SKIN_IDS`, `TRAY_IDS`, or `PARTICLE_IDS` in [`src/storage/save-code.ts`](../src/storage/save-code.ts) (`SAVE-COMPAT-01`).
   - Add the catalog entry in [`src/ui/catalog-meta.ts`](../src/ui/catalog-meta.ts) (re-exported by [`src/main.ts`](../src/main.ts)) and the `.swatch-<id>` preview in [`src/styles/themes-and-nav.css`](../src/styles/themes-and-nav.css).
   - Add the shader/palette branch in [`src/render/render-types.ts`](../src/render/render-types.ts) and [`src/render/shaders-3d.ts`](../src/render/shaders-3d.ts) / [`shaders-tray-materials.ts`](../src/render/shaders-tray-materials.ts).
2. **Single-Call File-Size Budget (`ARCH-ERGONOMICS-01`) & Rule Cap (`RULE-BUDGET-01`)**:
   - Every repository `.ts`, `.css`, `.html`, `.md`, `.js`, `.json`, `.jsonc`, or `.svg` file (except `package-lock.json`) must stay `<= 800 lines` and `<= 45,000 bytes` (aim for `<= 750 lines`), and `AGENTS.md` / `GEMINI.md` are additionally capped at `<= 23,500 bytes` (`RULE-BUDGET-01`, staying below Antigravity's `24,000`-byte always-on rule truncation limit), verified by [`tests/unit/sanctums-and-architecture.test.ts`](../tests/unit/sanctums-and-architecture.test.ts).
   - Multi-pass render logic lives in `src/render/pass1..3*.ts`, `particle-fx.ts`, `shred-style-fx.ts`, `shred-gate-bursts.ts`, `relic-awakening-fx.ts`, and `canvas2d-fallback.ts` via `RenderPassContext`; UI views live in `src/ui/*.ts` via `AppViewContext`; domain barrels (`physics.ts`, `gate-clearance.ts`, `board.ts`, `generator.ts`, `mesh-generator.ts`, `renderer-3d.ts`, `pointer-controller.ts`, `save-code.ts`, `main.ts`) re-export extracted sub-modules.
3. **Public Repository Portability & Zero Machine-Specific Bindings (`REPO-PORTABILITY-01`)**:
   - Because this repository is public (`MIT`), never commit secrets, API keys, `.env*` files, `.certs/` private keys, Cloudflare `account_id`/`zone_id` bindings, private LAN IPs, or machine-specific paths (`/Users/<user>`, `/home/<user>`, `C:\Users\<user>`, `.gemini/<dir>`).
   - Resolve filesystem paths in Vite configs, build/icon/harness scripts, and tests via `process.cwd()` or `fileURLToPath(new URL(..., import.meta.url))` with optional environment overrides (e.g., `VISUAL_OUT_DIR`), enforced automatically in [`tests/unit/sanctums-and-architecture.test.ts`](../tests/unit/sanctums-and-architecture.test.ts).
4. **Docs, Comments & Test Coverage Sync (`DOC-TEST-SYNC-01`)**:
   - Before finalizing any change, audit [`README.md`](../README.md), [`AGENTS.md`](../AGENTS.md), the affected `docs/*.md` guide(s), JSDoc/inline comments, [`tests/unit/`](../tests/unit/), and [`tests/e2e/`](../tests/e2e/) so documentation stays accurate and new or changed behavior has strong automated test coverage (see `AGENTS.md §4`).
