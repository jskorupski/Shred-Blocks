# AGENTS.md — Agentic Engineering Guide for ShredBlocks: Color Jam

Authoritative engineering entrypoint for autonomous coding agents and contributors working on **ShredBlocks: Color Jam**. ## 1. Core Architectural & Product Invariants (NON-NEGOTIABLE)

1. **100% Free-to-Play, Closed-Loop Ludological Core & Honest Privacy (`LUDO-CORE-01`, `ECON-01`–`04`, `ECON-V2`, `MAP-MODE-SPLIT-01`, `MODE-ISOLATION-01`, `ZEN-SKIP-GUARD-01`, `STREAK-INTEGRITY-01`, `ZEN-STARS-01`, `ANALYTICS-HONESTY-01`)**:
   - Never add ad SDKs, paid currency, stamina bars, or paywalls. Keep **Unlimited Lives (`F-01`)**, **Free Zen Blessing Continues** (`1 / 4` unique Zen clears, cap `3`), **Zen-Only Free Level Skips (`0 Coins`, `F-04`)**, and **3 Free Undos (`F-08`)** + accidental-restart recovery (`preRestartSnapshot`) on every stage. When optional build-time GA4 or Cloudflare analytics (`ANALYTICS-01`) can run on hosted builds, never claim unconditional "zero trackers / zero telemetry" in user-facing copy (`ANALYTICS-HONESTY-01`).
   - **3 Independent Mode Ladders (`modeState[mode]`), Mid-Stage Resume (`SESSION-RESUME-01`) & Mode Isolation (`MODE-ISOLATION-01`)**: `'CHALLENGE'` (move budget + coalescing + `FINAL-TOUCH-01`, `1–3★` via `STARS-SLACK-01`, Continue caps `1★`), `'ZEN'` (untimed, `bombsInert` `ZEN-CALM-01`, `1★ / 3` clears + `1 🌿 / 4` clears), and `'TIMED'` (`TIMED-BOMB-01` move-paced fuses, `1–3★`). Exiting a live board to Map/Themes and returning to the **same** `(levelId, playMode)` resumes `BoardState` (`canResumeBoardImpl` / `resumeOrLoadLevelImpl`); `↻ Restart`, picking another stage, or switching modes loads a clean Move-0 board (`boardPlayMode = activeMode`, `undoStack = []`, `preRestartSnapshot = null`, drags/targeting cancelled) without clobbering `modeState[mode].currentLevelId`.
   - **Genuine-Clear Progression, 50-Skip Cap & Streak Integrity (`ZEN-SKIP-GUARD-01`, `STREAK-INTEGRITY-01`)**: Free skips exist strictly in `'ZEN'`, cap at `ZEN_MAX_CONSECUTIVE_SKIPS = 50` trailing un-cleared stages (`canSkipZenLevel`), and never advance global Power-Up unlocks (`getEffectiveBoosterUnlockLevel`) or Milestone Chests (`countUniqueClearedLevels` / `10`). `winStreak` increments only on per-mode first clears (`!isZenRun && isFirstClear`), pauses across normal `'ZEN'` play/`Restart`/`‹ Map`, and resets on failure or mid-run `CHALLENGE`/`TIMED` mode switch (`isBoardRunStarted(board)`).
   - **Boosters & Undo (`UNDO-RES-01`)**: `UNDO (L1, 60c)`, `HINT (L2, 80c: hintMove + 2 Free Moves / +10s TIMED)`, `HAMMER (L8, 140c)`, `ROCKET (L18, 220c)`, `VACUUM (L30, 350c)`. Use `carryLiveResourcesIntoUndo` (preserving live `timerRunning` across Move-0 `TIMED` undos), charge before applying, clear `undoStack` on `HAMMER`/`ROCKET`/`VACUUM`, and lock `#level-jump-input` to `1 .. modeState[activeMode].highestUnlocked`.
2. **Local Process, Port, Git & Sandbox SOP (`SANDBOX-SOP-01`, `AGENT-HARNESS-01`, `GIT-COMMIT-SOP-01`)**:
   - **Never leak Vite or Chromium processes.** Spawn `./node_modules/.bin/vite` directly (never `npx vite`). Ports: Playwright E2E & visual goldens `4178` ([`playwright.config.ts`](playwright.config.ts) / [`playwright.visual.config.ts`](playwright.visual.config.ts) — never concurrent), 45-shot harness `4179` ([`scripts/visual-harness.ts`](scripts/visual-harness.ts)), UI probe `4180` ([`scripts/ui-probe.ts`](scripts/ui-probe.ts)), LAN HTTPS `8443`.

For custom checks, place an `.mts` file in `<scratch-dir>` using [`scripts/lib/agent-harness.ts`](scripts/lib/agent-harness.ts) (`pathToFileURL`, `--out-dir` CLI arg, no `VAR=val` env prefixes — see [`docs/AGENT_VERIFICATION_PLAYBOOK.md`](docs/AGENT_VERIFICATION_PLAYBOOK.md)). ## 4. Mandatory Ludological Impact Gate & Verification Workflow

0. **Mandatory 5-Question Ludological Impact Gate (`LUDO-CORE-01`)**:
   - Before editing any play mode, booster, skip, continue, undo, streak, chest, payout, price, or progression rule, load [`docs/PROGRESSION_AND_ECONOMY.md`](docs/PROGRESSION_AND_ECONOMY.md) and verify all 5 conservation invariants hold (`false` to exploits, `true` to balance):
     1. *Zero Infinite Faucets*: Replaying, restarting, undoing, skipping, or switching modes can never farm unbounded Coins, Stars, Zen Blessings, Streaks, or Chests.
     2. *Strict Mode State Isolation (`MODE-ISOLATION-01`)*: `undoStack`, `preRestartSnapshot`, `freeMovesRemaining`, `freezeRemainingSec`, `bombsInert`, `timerRunning`, and active drags never cross a mode boundary.
     3. *Genuine-Clear Gating (`ZEN-SKIP-GUARD-01`)*: `0`-cost Zen skips (`<= 50` consecutive) never advance global Power-Up unlocks (`L2/8/18/30`), Milestone Chests (`every 10 unique clears`), or `winStreak`.
     4. *100% Booster-Free Solvability & Faucet/Sink Equilibrium*: Every stage stays `solveBoard()`-solvable without boosters while booster sinks (`60..350c`), Continue (`150c` / `1 🌿`), and cosmetics (`250..1200c`) stay balanced against first-clear vs. `20%` replay rewards.
     5. *Append-Only Save Conservation (`SAVE-COMPAT-01`)*: Existing `v1`, `0xa5`, and `[0xa6, 0x4d]` saves migrate losslessly without resetting earned currency, stars, or unlocks.
0b. **Mandatory Docs, Comments & Test Coverage Sync Gate (`DOC-TEST-SYNC-01`)** (before running final verification & before committing):
   - *User-Facing Docs*: Audit [`README.md`](README.md) (features, controls, scripts, stack) and update it whenever player-visible behavior, modes, accessibility, or workflows change.
   - *Agent Docs*: Update [`AGENTS.md`](AGENTS.md), [`docs/ARCHITECTURE_AND_RULES.md`](docs/ARCHITECTURE_AND_RULES.md), and the matching `docs/*.md` guide(s) (including module tables, test suite counts, and new invariants) so agent instructions match the live codebase.
   - *Comments & JSDoc*: Ensure every new/modified function or non-obvious invariant has concise JSDoc and self-contained why-comments with zero stale references.
   - *Unit & E2E Coverage*: Audit [`tests/unit/`](tests/unit/) and [`tests/e2e/`](tests/e2e/) for gaps—do not rely only on pre-existing checks passing. Add focused unit tests and/or Playwright E2E coverage for new behavior, edge cases, performance/prewarm contracts, and regression fixes, keeping every file `<= 800 lines`.
0c. **Systematic Sibling Bug-Class Sweep & Upfront Root-Cause Headline (`SIBLING-BUG-SWEEP-01`)**:
   - When fixing any reported bug, audit the entire sibling class (all 18 mechanics, 5 skins/trays/particles, 3 modes, 4 `C1-03` cascade entry points, and `getMovedGroupBlocks` glued/Stone clusters) for the same defect class, and state a 1–2 sentence root-cause headline before launching multi-turn background verification suites.

Run fast `./node_modules/.bin/tsc --noEmit` (`~2s`) first after `.ts`/test edits before the `35s` solver run, and always rebuild `dist/` before Playwright, `ui-probe.ts`, or `visual-harness.ts`.

## 5. Public Repository Portability, Security & Upstream Hosting (`REPO-PORTABILITY-01`)

- **Public Repo Hygiene & Zero Machine-Specific Bindings (`REPO-PORTABILITY-01`)**:
  - This is a public open-source repository (`MIT`). **Never** commit secrets, API keys, tokens, `.env*` files, TLS private keys/certs (`.certs/`), Cloudflare `account_id`/`zone_id` values, private LAN IPs, or machine-specific filesystem paths (`/Users/<user>`, `/home/<user>`, `C:\Users\<user>`, `.gemini/<dir>`).
  - All scripts, configs, and tests must resolve paths portably via `process.cwd()` or `fileURLToPath(new URL(..., import.meta.url))` (with optional env-var overrides like `VISUAL_OUT_DIR`), enforced automatically by [`tests/unit/sanctums-and-architecture.test.ts`](tests/unit/sanctums-and-architecture.test.ts).
- **Browser Support**: Baseline Widely Available + progressive enhancement (`@supports` `in oklab`/`in oklch`, `devicePixelContentBoxSize` with `devicePixelRatio` fallback).
- **Upstream Fork Customization**: Only `https://shredblocks.skorupski.org` references ([`index.html`](index.html), [`public/robots.txt`](public/robots.txt), [`public/sitemap.xml`](public/sitemap.xml), [`src/storage/save-manager.ts`](src/storage/save-manager.ts)) and optional Cloudflare config ([`wrangler.jsonc`](wrangler.jsonc), [`public/_headers`](public/_headers)) are deployment-specific; `dist/` runs on any static host.
