## 1. Core Architectural & Product Invariants (NON-NEGOTIABLE)

Every change to the codebase must preserve these invariants:

1. **100% Free-to-Play, Zero Ads, Zero IAP, Zero Dark Patterns & Balanced Economy v2 (`ECON-01`–`ECON-04`, `ECON-V2`)**:
   - Never add ad SDKs, paid currency packs, energy/stamina bars, or paywalled levels.
   - **Unlimited Lives (`F-01`)**, **1-Tap Zen Mode Rescue**, and **Free Level Skip (`F-04`)** (`0 Coins` via `#btn-skip-hud`, Pause modal, or Failure modal) must remain available on every level.
   - **3 Play Modes (`PlayMode`) & Anti-Cheese Mode Switching**:
     - **`'CHALLENGE'` (Default — Tactical Move Budget)**: `moveLimit = computeDefaultMoveLimit(parMoves, difficulty, levelId)` (`parMoves + 6` on `L1–12` $\rightarrow$ `+5 / +4` on `L13–25` $\rightarrow$ `+5` breathers or `+4 / +3 / +2` for `NORMAL / HARD / SUPER_HARD` on `L26+`) with **Touch-Move Coalescing** (`lastMovedBlockId === block.id && !lastMoveDidShred` adjustments or gate finishes count as `1` move tick). Awards `1–3` Gold Stars, Flow Streak bonuses, and 25-Star Reliquary Chest progress.
     - **`'ZEN'` (Sanctuary Flow)**: Unlimited moves, untimed, advances campaign freely with a **`🌿 Zen`** badge (`zenCleared: true`, `0` Gold Stars, pauses rather than resets `winStreak`). Switching `Challenge`/`Timed` $\rightarrow$ `Zen` mid-level preserves the live board (`runTouchedZen = true`, defusing `0`-count bombs); switching `Zen` $\rightarrow$ `Challenge`/`Timed` after `movesCommitted > 0 || runTouchedZen` restarts from Move 0 so Gold Stars cannot be cheesed on the final move.
     - **`'TIMED'` (Speed Rush)**: Calibrated countdown (`round(minMoves * secPerMove + 12)` at `4.6 / 4.0 / 3.5s` per move), awarding `1–3` Gold Stars.
     - **Stars, Fuses & Undo Integrity (`STARS-SLACK-01`, `TIMED-BOMB-01`, `UNDO-RES-01`)**: `computeEarnedStars` scales `CHALLENGE` tiers to `slack = moveLimit - parMoves` (`3★ <= par + floor(slack/3)`, `2★ <= par + floor(2*slack/3)`) and caps any Continue at `1★` (`continuesUsed`). `TIMED` bombs tick every `getTimedBombTickSec(board)` (never `1/sec`). Undo must use `carryLiveResourcesIntoUndo` (clock, fuses, Stasis, freeze, Continues never rewind); charge boosters/Continues before (or roll back with) their effect. **Zen bombs are inert** (`bombsInert`, `ZEN-CALM-01`); at `0` moves the last-moved unshredded block may still finish free (`hasFinalTouchGrace`, `FINAL-TOUCH-01`, other moves rejected); idle `scheduleStuckBoardCheckImpl` warns only on provably unsolvable boards (`searchExhausted`, `STUCK-01`).
   - **3 Free Undos Per Level (`F-08`)** + accidental level restart recovery (`preRestartSnapshot` in [`src/main.ts`](src/main.ts)) must remain intact.
   - **Progressive Power-Up Unlocking, Stasis & Rarity Scarcity (`ECON-01`–`ECON-04`)**:
     - Power-ups unlock gradually (`UNDO: L1`, `FREEZE: L2`, `HAMMER: L8`, `ROCKET: L18`, `VACUUM: L30`) across 5 rarity tiers (`COMMON..LEGENDARY`) at `60 / 80 / 140 / 220 / 350 Coins` (`120` starter coins + `1` unit per booster). **`FREEZE` (`❄️`)** grants **`+2` Stasis Moves** (`stasisMovesRemaining += 2`, pausing `movesRemaining` and Bombs for 2 move ticks) + `hintMove` in `CHALLENGE`/`ZEN`, or `+10s` clock/bomb freeze + `hintMove` in `TIMED`.
     - Economy v2 payouts (`15 / 25 / 40 Coins` first Gold clear, `20%` min `3` replay, `+5c/★`, Flow Streak `+5..+25c`, Zen `+10c`/`+2c`), 3 chest tracks (**Shredder** `+50c + 1 Booster` / `100` blocks, **Milestone** `+75c + 1 Booster` / `10` levels, **25-Star Reliquary** `+90c + 1 Booster` / `25` Gold Stars via `pickRarityWeightedBooster`), tiered Themes (`[0, 250, 450, 750, 1200]`), `150c` Continue (`+5` Moves / `+20s`), and locked Stage Jump (`1 .. highestLevelUnlocked` via `setCurrentLevel(id, allowJump = false)`) keep coins and power-ups meaningful.
   - **Destructive Boosters Clear Undo Stack (`F-08` / `MECH-10`)**: Executing `HAMMER`, `ROCKET`, or `VACUUM` must clear `this.undoStack` so consumed inventory boosters cannot be refunded via Undo.
2. **Local Process, Browser, Port & Sandbox Execution SOP (`SANDBOX-SOP-01`)**:
   - **Never leak orphan dev servers (Vite) or headless browser (Chromium) processes.** Always spawn `./node_modules/.bin/vite` directly—**never** wrap Vite in `npx vite`.
   - Playwright uses strict port `4178` ([`playwright.config.ts`](playwright.config.ts)); the visual harness uses strict port `4179` ([`scripts/visual-harness.ts`](scripts/visual-harness.ts)). Check `if (proc.exitCode !== null)` inside readiness loops and register `exit`/`SIGINT`/`SIGTERM` handlers with `SIGTERM` + `SIGKILL` fallback.
   - **Sandbox vs. `BypassSandbox: true` First-Try Matrix (DO NOT WASTE FAILED SANDBOX ATTEMPTS)**:
     - **Mutating `git` Commands -> `BypassSandbox: true` Immediately**: The macOS sandbox blocks writes inside `.git/` (`Unable to create '.../.git/index.lock': Operation not permitted`). **Never** attempt mutating `git` commands (`git add`, `git commit`, `git reset`, `git checkout`, `git switch`, `git stash`, `git rebase`, `git merge`, `git cherry-pick`, `git tag`, `git branch -d/-m`, `git fetch`, `git pull`, `git push`) with `BypassSandbox: false`—always pass `BypassSandbox: true` on the **first** call, as separate prefix-matchable commands (`git add -A`, then `git commit -m "..."` without `&&`, `$()`, or heredocs). Read-only `git` commands (`git status`, `git diff`, `git log`, `git show`) work in the sandbox (`BypassSandbox: false`).
     - **Loopback Browser/Server Suites -> `BypassSandbox: true` Immediately**: The sandbox blocks `127.0.0.1` loopback sockets (`EPERM`, making Playwright report `http://127.0.0.1:4178 is already used`). Always run `./node_modules/.bin/playwright test ...`, `./node_modules/.bin/tsx scripts/visual-harness.ts`, and any local Vite+Chromium capture scripts with `BypassSandbox: true` on the **first** call (invoke `./node_modules/.bin/playwright` / `./node_modules/.bin/tsx` directly rather than `npm run` wrappers so prefix approvals reuse cleanly).
     - **Sandboxed Commands (`BypassSandbox: false`)**: Run `npm run lint`, `npm run lint:fix`, `npm run test:unit`, `npm run build`, `./node_modules/.bin/tsx scripts/generate-icons.ts`, and file/text tools with `BypassSandbox: false`.
   - **LAN HTTPS Preview Server SOP (`vite.lan.config.ts`)**: Spawn `./node_modules/.bin/vite --config vite.lan.config.ts` directly (`IsDaemon: true`, `BypassSandbox: false`) on `0.0.0.0:8443` (auto-provisions `.certs/key.pem` & `cert.pem`). Terminate the daemon task directly when done.

## 4. Engineering & Testing Guardrails (Lessons Learned)

1. **Self-Contained Documentation & Comment Hygiene**:
   - Code comments, test descriptions, and docs (`src/`, `tests/`, `scripts/`, `docs/`, `README.md`, `AGENTS.md`) must **only** reference self-contained domain concepts or git-tracked invariants defined in [`docs/ARCHITECTURE_AND_RULES.md`](docs/ARCHITECTURE_AND_RULES.md) and [`AGENTS.md`](AGENTS.md)—never transient plan steps, review rounds, or temporary bug labels.
2. **3D Block Top-Surface Z-Layer Hierarchy (`zCbSymbol = 0.692`)**:
   - Studded skins (`classic_studs`, `gummy_jelly`, `neon_cyber`) have top studs reaching `Z = 0.660` (outer) and `Z = 0.677` (inner multi-layer core). Surface badges that must sit above studs—such as `CB_0..9` colorblind symbols—must render at `zCbSymbol = zLift + 0.692 * scaleZ` and shift to `(0.21, 0.21)` on multi-layer or center-badged cells (see Z-Layer Hierarchy in [`docs/ARCHITECTURE_AND_RULES.md`](docs/ARCHITECTURE_AND_RULES.md)).
3. **WebGL2 Canvas Pixel-Diff Verification for Settings × Custom Themes**:
   - Always maintain the `#game-canvas` screenshot buffer diff in [`tests/e2e/shredblocks.spec.ts`](tests/e2e/shredblocks.spec.ts) verifying that toggling High Contrast and Colorblind Symbols on non-default custom themes (`neon_cyber` + `warm_birch`) produces measurably distinct WebGL2 frames.
4. **Row-Span Plinth Merging (`plinthSpans`) for 120Hz Frame Budget (`<= 6.5ms`)**:
   - Never issue per-cell `drawMesh` calls for architectural plinths under sculpted or multi-room boards (`L14+`, `L25+`); merge contiguous row spans (`plinthSpans` in [`src/render/renderer-3d.ts`](src/render/renderer-3d.ts)) so Pass 1 stays at `~15–24` draw calls.
5. **4-Entry-Point Clear & Barrier Unlock Parity (`C1-03`)**:
   - All 4 block-clearing entry points (`commitBlockMove`, `applyBoosterHammer`, `applyBoosterRocket`, `applyBoosterVacuum`) must share post-clear side effects (`triggerCarrierItems`, `stepPortcullisBarriersOnShred`, `trySpawnReadyGenerators`, and `⛩️ Portcullis Opened!` toast), while Booster clears additionally invoke `rescueDynamicGatesOnBoard` + `autoAdvanceColorQueues(board, true)` (`C1-03`).
6. **Visual Harness Context Isolation**:
   - In [`scripts/visual-harness.ts`](scripts/visual-harness.ts), explicitly reset `setHighContrast(false)`, `setColorblindMode(false)`, and `setTheme('classic_studs', 'industrial_slate', 'micro_cubes')` after any custom-state capture.
7. **Single-Call Agentic File-Size Invariant (`ARCH-ERGONOMICS-01`) & Atomic Commit Hygiene**:
   - Keep every `.ts`, `.css`, `.html`, `.md`, `.js`, `.json`, `.jsonc`, or `.svg` file (except `package-lock.json`) `<= 800 lines` and `<= 45,000 bytes` (aim for `<= 750 lines`). Place new features in focused domain sub-modules re-exported via domain barrels, and keep git commits atomic and verified.
8. **Open-Space 2D Drag Glide & Continuous Wide-Gate Span Capture (`DRAG-04` / `F-01`)**:
   - `sweepBlockToTarget` ([`src/core/physics.ts`](src/core/physics.ts)) sweeps both axes continuously in open space with `CORNER_BEVEL_THRESHOLD = 0.35`. `checkMidDragGateCapture` ([`src/core/gate-clearance.ts`](src/core/gate-clearance.ts)) evaluates continuous span containment (`[minSpan - 0.45, maxSpan + 0.45]`) rather than `<= 0.15` integer snapping so wide gates have zero center deadzones.
9. **Sealed Mystery Vault Stasis & Multi-Vault Clamping (`VAULT-01` / `VAULT-02`)**:
   - While `bar.isVault && !bar.open`, `rebuildOccupancyGrid` preserves `-3` (`BARRIER`) across `bar.cells` and skips concealed blocks (`isBlockInSealedVault`), while `pickBlockAtBoardPoint` checks `getSealedVaultAtCell` before halo fallback. `stepPortcullisBarriersOnShred` sorts closed barriers ascending by `shredsRemaining` so multi-vault stages (`Level 74`) never prematurely clamp higher vaults, and `autoAdvanceColorQueues` tracks `unlockedSupply[c]` (`levelId <= 25` or `forceRescue`).
10. **Dual-Layer Storage, 53-Bit Binary Save Codec & O(1) Map Rendering (`STOR-01`, `STOR-02`, `ENDLESS-SAVE-01`, `SAVE-SEC-01`)**:
    - `SaveManager` ([`src/storage/save-manager.ts`](src/storage/save-manager.ts)) dual-writes to `localStorage` (`shredblocks_save_v1`) and `IndexedDB` (`shredblocks_db_v1`), reconciling via `writeSeq`, migrating v1 saves via `economyVersion: 2`, and evicting `PRE_IMPORT_BACKUP_KEY` on `QuotaExceededError`.
    - `encodeSaveCode` / `decodeSaveCode` ([`src/storage/save-code.ts`](src/storage/save-code.ts)) uses `0x02` columnar binary encoding (including `zenClearedMask` & `starChestsClaimed`), 53-bit varint math (`writeVarint` / `readVarint` — never 32-bit shifts!), and O(N) LZ77 (`compressLz77`), with `{ qrCompact: true }` capping QR exports at `1,500` records for QR Version 40 safety.
    - **Untrusted Save Input (`SAVE-SEC-01`)**: Treat `#import=`, pasted codes, JSON files & storage as hostile. `validateSavePayloadV1` rebuilds a whitelisted payload; save data renders strictly via `textContent`/`.value` (never `innerHTML`); keep `index.html` CSP (`script-src 'self'`, no `unsafe-eval`) + `frame-ancestors 'self'` + `X-Frame-Options: SAMEORIGIN` in `public/_headers`, `vite.config.ts` & `vite.lan.config.ts` ([`save-security.test.ts`](tests/unit/save-security.test.ts)).
    - `renderRoadmapImpl` ([`src/ui/roadmap-and-themes-view.ts`](src/ui/roadmap-and-themes-view.ts)) uses O(1) `getCampaignRoadmapMeta()` / `getLevelRoadmapMeta()` ([`src/levels/catalog.ts`](src/levels/catalog.ts)) and windows Endless stages (`301..306` + active/frontier windows) so `#screen-home` opens in `< 1ms` without synchronous `solveBoard()` passes, while `#level-jump-input` is locked to `1 .. highestLevelUnlocked` (`__SHREDBLOCKS_DEBUG__.loadLevel` passes `allowJump = true`).
11. **Non-URL Browser History Stack, Cross-Screen Button Colors & Touch `:hover` Guard (`NAV-HISTORY-01`, `UI-BTN-COLOR-01`, `SETTINGS-MATRIX-01`)**:
    - Browser Back/Forward (`openTitleScreenImpl`, `switchScreenImpl`, `handlePopstateNavigationImpl` in [`src/ui/modals-and-save-transfer.ts`](src/ui/modals-and-save-transfer.ts)) uses state-only `history.pushState` / `replaceState` without mutating URL pathname/query/hash—preserving offline SW caching while seeding `home` beneath `game` on Title launch.
    - Keep semantic button color families consistent across all screens: **Map** = Warm Terracotta-Amber (`.btn-sanctuary` / `.title-map-pill`), **Install** = Seafoam-Teal (`.btn-install` / `.title-install-pill`), **Primary Play/Resume/Next** = Luminous Jade-Teal (`.btn-primary` / `.tab-play-cta`), **Secondary/Utility** = Amethyst-Slate (`.btn-secondary` / `.title-utility-pill`). Gate `:hover` inside `@media (hover: hover)` so touch screens never stick synthetic `:hover`, and keep `.title-crest-banner` borderless in `body.high-contrast`.
12. **WebGL2 Satin Astrolabe Title, Block Skins & Tray Materials (`STONE-TABLET-01`, `MYSTIC-RELIC-01`, `RELIC-AWAKEN-01`, `BLOCK-STONE-01`, `TRAY-IDENTITY-01`)**:
    - Never set fragment `alpha < 1.0` on Pass 1/Pass 3 meshes (`MAIN_FRAGMENT_SHADER` in [`src/render/shaders-3d.ts`](src/render/shaders-3d.ts)), which causes X-ray floor bleed under `DEPTH_TEST` + `BLEND`. Keep `blueprintAlpha = 1.0`, `zRelief = 0.76`, `isStoneRuin` (`blueprintMix > 0.45`) skipping HUD/modifiers across Passes 1–4, and snap `blueprintMix = 0` on direct `loadLevelImpl` / `switchScreenImpl`.
    - Default skin is `classic_studs` (`0c`); `relic_stone` (`250c`, style `6` on 8-fan `meshOuterWorn` / `meshInnerCoreWorn` with `applyPolyominoWearUvs`) uses matte `0.83` worn stone + analytic-offset `stoneRelief` (`runeDist` via `u_blockSeed`; neutral `color: 0` sliders share `meshOuterWorn` + style `6`). Floor tiles (`STONE_SURFACE_STYLE = 5`) and plinths/walls (`TRAY_WALL_STYLE = 7`) use `applyTrayMaterial` (`u_trayMaterial = 0..4`; full pipeline in [`docs/ARCHITECTURE_AND_RULES.md`](docs/ARCHITECTURE_AND_RULES.md)).
